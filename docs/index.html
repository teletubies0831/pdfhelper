PDFPal

隐私政策

生效日期：2026 年 8 月 17 日

PDFPal 是一款在浏览器中运行的 PDF 阅读扩展。我们尊重你的隐私，并按本政策说明扩展处理哪些数据、为什么处理以及你可以如何控制这些数据。

1. 本地处理与保存的数据

PDF 文件解析、阅读位置、批注、阅读卡片、知识库、对话记录、长期记忆和扩展设置主要在你的设备上处理，并保存在浏览器扩展的本地存储或 IndexedDB 中。你配置的 API Key 也只保存在当前浏览器的扩展存储中；PDFPal 不运营用于接收或转存该密钥的服务器。

2. AI 功能与第三方数据传输

当你主动使用聊天、翻译、总结、论文卡片、阅读模式识别、图片分析或其他 AI 功能时，PDFPal 会把完成任务所需的数据直接发送到你选择并配置的第三方 AI 服务商。这些数据可能包括你的问题、必要的 PDF 文本片段或文档采样、截图、对话上下文、已启用的记忆以及工具结果。API Key 会随请求发送给该服务商用于身份验证。

PDFPal 不运营 AI 请求中转服务器。第三方服务商如何保存和使用数据，受该服务商自己的条款和隐私政策约束。请勿向不信任的服务商发送敏感或机密内容。

3. 联网文献功能

当你使用相关论文、会议等级或文献检索功能时，扩展可能向 Semantic Scholar、OpenAlex、Crossref、DBLP 或中国计算机学会网站发送论文标题、作者、DOI、检索词等必要信息。相关服务会按其各自的隐私政策处理请求。

4. 浏览器权限

  • tabs：打开 PDFPal 阅读器，并识别当前标签页中的 PDF 来源。
  • storage：在本地保存设置、阅读数据和 API 配置。
  • contextMenus：提供“发送给 PDFPal”等右键菜单。
  • 网站访问权限：读取用户选择打开的在线 PDF，并连接用户配置的 AI 接口及文献数据源。扩展不会向所有网页注入内容脚本。

5. 数据出售、广告与分析

PDFPal 不出售个人数据，不使用数据投放广告，也不包含开发者运营的遥测或行为分析服务。

6. 数据保留与删除

本地数据会保留到你在扩展中删除相关记录、清除扩展站点数据或卸载扩展。发送给第三方服务商的数据保留期限由该服务商决定；你应通过对应服务商的账户或支持渠道行使相关权利。

7. 安全

PDFPal 要求公网 AI API 地址使用 HTTPS。本机 localhost 或 loopback 开发服务可以使用 HTTP。请妥善保管 API Key，并只配置你信任的服务地址。

8. 儿童隐私

PDFPal 不以儿童为目标用户，也不会主动收集儿童个人信息。

9. 政策更新与联系

政策发生实质变化时，我们会更新本页的生效日期，并通过扩展更新或商店产品页提供新版本。如对隐私有疑问，请通过 Microsoft Edge 加载项商店中 PDFPal 产品页列出的支持渠道联系发布者。
