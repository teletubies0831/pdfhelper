# PDF Read Helper

这是一个基于 `WXT + TypeScript + PDF.js Viewer` 的 Edge 扩展原型。产品围绕 PDF 深度阅读、全文理解、长期记忆和知识卡片设计，不定位为所有网页通用的聊天侧栏。

## 当前验证范围

- 点击扩展图标打开 Edge 侧边栏；
- 侧边栏只在识别为 PDF 的标签页启用；
- 在 Edge 原生 PDF 中选择文字；
- 通过右键菜单发送文字到 PDF Helper；
- 支持“解释”“翻译”“加入知识卡片”三种请求类型；
- 验证插件能否取得当前原生 PDF 的完整文件；
- 统计总页数、可提取文字页数、字符数，并显示文字预览；
- 增强阅读器使用 PDF.js 官方 Viewer 层，支持文字选择、复制、连续滚动、链接和 `Ctrl+F` 全文查找。
- 支持高亮、自由画笔、添加文本、撤销、重做和导出带批注的新PDF。
- 普通 `Ctrl+C` 保持原始选区内容；“整理复制”额外清理多余空格、软连字符和段内强制换行。

当前尚未调用大模型。“解释”和“翻译”只验证交互链路，下一阶段再接入模型 API。

## 构建

```powershell
pnpm install
pnpm build
```

构建产物：

```text
.output/edge-mv3
```

## 在 Edge 中测试原生 PDF 模式

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 首次安装时点击“加载解压缩的扩展”，选择 `.output/edge-mv3`。
4. 已经安装过时，点击 PDF Read Helper 卡片上的“重新加载”。
5. 直接使用 Edge 打开一个本地或在线 PDF，不要先进入增强阅读器。
6. 点击工具栏中的 PDF Read Helper 图标，确认右侧出现侧边栏。
7. 在原生 PDF 中选中一段文字并点击右键。
8. 选择“发送给 PDF Helper”，再选择“解释这段内容”“翻译成中文”或“加入知识卡片”。
9. 确认选中的文字出现在右侧面板。
10. 点击“读取当前PDF”，检查总页数、文字页数和字符数。

如果本地 PDF 中看不到扩展菜单，请进入扩展详情页，开启“允许访问文件 URL”，然后刷新 PDF 页面再试。

## 两种阅读模式

- 原生模式：Edge 负责 PDF 的显示、搜索、缩放、目录、划词和批注，PDF Helper 负责 AI 与记忆。
- 增强模式：使用 PDF.js 官方 Viewer 层，不再是单 Canvas 演示版；未来用于自动定位、引用坐标和自定义批注。

## 当前验证结论

- 扩展不能依赖读取 Edge 内置 PDF 阅读器的内部 DOM；正确方式是取得原始 PDF 文件后自行解析。
- 对能够访问原始 URL 的本地或在线 PDF，可在保留原生阅读器的同时完成全文解析。
- 如果原始 URL 因权限、登录态或第三方阅读器封装而不可访问，用户可以手动选择同一 PDF。
- 扫描版 PDF 可能没有文字层，此时需要 OCR，不能仅凭 PDF 解析器解决。
- 测试使用的 16 页论文成功提取 16/16 页，共约 48,168 个字符。
- PDF 本身如果缺少正确的字符映射或阅读顺序，复制仍可能不准确；复杂双栏、公式和扫描件需要版面分析或 OCR 纠正。

## 增强阅读器批注

- “移动/选择”：恢复普通文字选择；单击已有文本或画笔批注后可拖动，双击文本可重新编辑。
- “高亮”：选中高亮工具后拖选文字，生成黄色高亮批注。
- 高亮颜色：工具栏颜色选择器支持任意颜色；选中已有高亮后修改颜色，可更新该高亮。
- 右键快速高亮：先拖选文字，再点击右键，直接选择黄色、绿色、蓝色、粉色或橙色。
- 高亮几何：蓝色临时选区与最终高亮共用 `--pdf-selection-height-ratio`，导出的PDF也使用相同高度。
- 批注选择：在“移动/选择”模式下单击高亮、文本或画笔批注可选中；可拖动，按 `Delete` 或操作条的“删除”移除，撤销可恢复。
- 高亮右键菜单：支持复制、整理后复制、修改颜色、添加/编辑笔记和删除高亮。
- 高亮笔记：保存后高亮出现笔记标记；再次单击高亮显示笔记，笔记随批注PDF导出。
- 高亮取消选择：点击PDF空白区域会取消当前高亮选中状态。
- 快速高亮不会切换工具，创建后仍保持“移动/选择”模式。
- 笔记弹层只有用户填写的笔记文本可选择和复制，标题、引用及操作区不可选择。
- “画笔”：在页面上自由绘制。
- “文本”：点击页面位置后输入自己的文字。
- “撤销/重做”：操作当前批注历史。
- 普通复制：选中文字或编辑文本批注时使用 `Ctrl+C`，不会再被批注编辑器拦截。
- “整理复制”：需要粘贴到笔记或模型时，清理当前选区的多余空格、断词和换行。
- 文本批注：单击选择后拖动位置，方向键微调；双击修改；选中批注后 `Ctrl+C`、`Ctrl+V` 可复制一份。
- “导出批注PDF”：将批注写入新PDF并下载，不覆盖原始文件。

## 主要入口

- `entrypoints/background.ts`：注册右键菜单、保存划词、打开侧边栏。
- `entrypoints/sidepanel/`：PDF Helper 侧边栏界面。
- `entrypoints/viewer/`：原有 PDF.js 增强阅读器。
- `shared/selection.ts`：划词请求的数据结构。
